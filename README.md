# SmartPark IoT

Protótipo escolar de estacionamento inteligente (dashboard + Flask + Firestore + Mercado Pago + Telegram + ESP32/Wokwi).

- `backend/`  API Flask
- `frontend/` Dashboard (Leaflet)
- `firmware/` Código ESP32 (Wokwi)
- `docs/`     Contrato da API, modelo do Firestore, relatório de testes

Nunca versionar `.env` nem a chave de serviço do Firebase.
